# باغ واژه 🌷

باغ واژه یک بازی اندرویدی کلمات فارسی با حال‌وهوای باغ و گل‌های رنگارنگ است.

## امکانات
- انتخاب حروف و ساخت کلمه فارسی
- جدول کلمات هر مرحله
- پنج مرحله نمونه با امکان پیشروی و شروع دوباره
- امتیاز برای کلمات پیدا شده
- راهنمای کلمه با تعداد محدود
- رابط فارسی و تم رنگی باغ
- ساخت خودکار APK با GitHub Actions

## دریافت APK
از بخش Actions مخزن، آخرین اجرای موفق گردش‌کار **Build Bagh Vaje Android APK** را باز کنید و در قسمت Artifacts فایل **bagh-vaje-android-apk** را دریافت کنید. فایل Artifact به صورت ZIP است؛ آن را استخراج کنید و فایل APK را روی دستگاه اندرویدی نصب کنید.

## فناوری‌ها
- Kotlin
- Android SDK
- Gradle
