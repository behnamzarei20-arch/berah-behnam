# بازی معمایی 2048

یک بازی پازلی اندروید با رابط فارسی، ساخته‌شده با Kotlin و Android Native.

## امکانات نسخه اول
- صفحه بازی ۴×۴
- حرکت با کشیدن انگشت در چهار جهت
- ادغام خانه‌های هم‌عدد و کسب امتیاز
- شروع مجدد بازی
- تشخیص پایان بازی
- ساخت خودکار APK با GitHub Actions

## ساخت APK
از بخش **Actions** مخزن، گردش‌کار **Build Android APK** را اجرا کنید. پس از موفقیت، فایل APK در بخش Artifacts همان اجرا قابل دریافت است.

## فناوری‌ها
- Kotlin
- Android SDK
- Gradle
